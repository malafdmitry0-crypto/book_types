# 10. Срез → указатель на массив: Go 1.17

Код главы: [example_test.go](../../lessons/reference/basics/example_test.go) · [failures_test.go](../../lessons/failures/failures_test.go).


> Цель главы: Понимать совместное использование памяти среза и массива.

Этот переход даёт доступ к началу среза как к массиву через указатель. Главный эксперимент — изменить элемент и увидеть изменение исходного среза.

```go
s := []int{10, 20, 30}
p := (*[2]int)(s)
p[0] = 99 // s[0] тоже стал 99

// _ = (*[4]int)(s) // panic: len(s) < 4
```

Проверяется `len`, а не `cap`. Конверсия не копирует элементы. Для `nil`-среза конверсия в `*[0]T` даёт nil-указатель; для пустого, но ненулевого среза — ненулевой указатель на массив нулевой длины. Это первый введённый в Go случай конверсии, способной вызвать runtime panic. Источник: [Go 1.17](https://go.dev/doc/go1.17#language).

Обратное представление массива как среза создаётся через slicing: `a[:]` или `p[:]`. Сам массив при `a[:]` должен быть адресуемым. Это операция slicing, а не `T(x)`.
