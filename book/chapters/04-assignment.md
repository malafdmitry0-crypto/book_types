# 4. Константы и присваивание

> Цель главы: Различать присваивание, константы и идентичность типов.

### 4.1. Нетипизированная константа

```go
const answer = 42
var a int8 = answer
var b float64 = answer
var c complex128 = answer

inferred := 42 // int: тип по умолчанию
const typed int = 42
// var d int64 = typed // typed уже имеет тип int

// _ = uint8(300) // ошибка компиляции: константа не помещается
// _ = int(3.9)   // ошибка компиляции: константа не представима как int
_ = int(3.0)      // допустимо: значение константы целое
```

Разница между константой и переменной объясняет, почему `uint8(300)` запрещено, а преобразование переменной со значением 300 даёт 44. Это не автоматическое расширение любых чисел. См. [Constants](https://go.dev/blog/constants).

### 4.2. Совместимость при присваивании

```go
type Numbers []int
var named Numbers = []int{1, 2}
var plain []int = named // одинаковые underlying types, один тип неименованный

type OtherNumbers []int
// var other OtherNumbers = named // оба типа определённые
other := OtherNumbers(named)       // явная конверсия допустима
```

Термины: `type ID int` создаёт **определённый тип**; его underlying type — `int`. Именованность, идентичность типов и возможность присваивания — разные понятия. Алиас сам по себе нового типа не создаёт.

Есть отдельные правила для интерфейсов, каналов, `nil` и параметров типов. Эти правила действуют также при передаче аргументов и возврате результатов. Нормативный список: [Assignability](https://go.dev/ref/spec#Assignability).

### 4.3. `nil`, указатели и адрес значения

```go
var p *int = nil
typedNil := (*int)(nil)
var s []int = nil
var m map[string]int = nil
var fn func() = nil
var ch chan int = nil
var x any = nil

n := 42
ptr := &n
value := *ptr
// _ = int(nil) // недопустимо
```

`&n` и `*ptr` — взятие адреса и разыменование. Они не являются конверсиями. С Go 1.26 `new(42)` создаёт отдельную переменную типа `int`, инициализирует её значением 42 и возвращает `*int`; это тоже не cast. Источник: [Go 1.26](https://go.dev/doc/go1.26#language).
