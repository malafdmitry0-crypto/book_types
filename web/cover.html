Главная идея: обобщить операции над коллекцией

В раннем Go алгоритм мог знать только длину, сравнение и перестановку. Конкретные элементы оставались внутри адаптера. В первых десяти главах проходим этот путь по исходникам нашего пакета algorithms и историческому sort.Interface.

Что видит общий алгоритм?

Выберите операцию. Вызовы показаны с подготовленными адаптерами; их полные определения разобраны в главах. Это иллюстрация API.

index, err := algorithms.Find(query)
// query: fractionQuery
// Результат — индекс в исходном []fraction.Fraction

Алгоритм знает Len и Match. Адаптер хранит дроби и условие; математическое равенство проверяет Fraction.Equal. Тип элемента не проходит через API алгоритма.
