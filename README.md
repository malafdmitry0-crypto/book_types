# Обобщённое программирование в Go

**Одна библиотека Find / All / Map — восемь подходов к реализации.**

Учебник объясняет, как развивались способы обобщения алгоритмов: конкретные типы и callback, индексы и замыкания, поведенческие интерфейсы, `interface{}`, reflection, генерация кода, параметры типов и итераторы.

**[Открыть HTML-учебник](index.html)** · **[Оглавление Markdown](book/README.md)** · **[Исполняемые реализации](examples/README.md)**

## Две части одного учебника

Основной курс — 12 глав вокруг одной задачи: найти пользователя, проверить условие для всех пользователей и получить `[]string` из `[]User`. Сравниваются связи типов в API, момент проверки ошибок, адаптеры, представление данных, стоимость и семантика вычислений. Реальные вехи Go показаны через `sort.Interface`, `sort.Search`, `sort.Slice`, `slices` и `iter`.

Справочник — все прежние 18 глав о конверсиях, интерфейсах, reflection, алиасах, дженериках и `unsafe`, сохранённые без изменений. Они остаются частью того же оглавления и HTML.

Find, All и Map — названия учебных алгоритмов. В частности, `slices.All` возвращает итератор и не является проверкой предиката «все подходят».

## Читать и редактировать

Откройте `index.html` в браузере двойным щелчком. Интернет и сервер не нужны. Есть поиск по полному тексту, две группы оглавления, переходы между главами, копирование примеров и печать всего учебника в PDF.

Введение позволяет переключать способы реализации Map и сравнивать код вызова, гарантии и ограничения. Это иллюстрация API, а не запуск Go в браузере.

Изменяйте Markdown в `book/chapters/`. После правок пересоберите HTML:

```sh
node scripts/build.mjs
```

Сборка использует только встроенные модули Node.js. Поддержан используемый набор Markdown: заголовки, абзацы, нумерованные списки, цитаты, таблицы, ссылки, жирный текст и код. Это специализированный сборщик, не универсальная реализация CommonMark. `index.html` не нужно редактировать вручную.

## Проверить алгоритмы

Требуется Go 1.23 или новее из-за итераторов. Из корня:

```sh
go -C examples test ./...
go -C examples vet ./...
go -C examples generate ./...
```

Полные реализации и тесты проверены на Go 1.25.4. Go-фрагменты в тексте могут опускать импорты и контекст вызова. Прежние справочные фрагменты не заявлены как прошедшие компиляцию; их исходные оговорки сохранены. Методика сравнения производительности дана в основном курсе, неподтверждённые benchmark-цифры не приводятся.
