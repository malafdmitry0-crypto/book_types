# 800 задач по типизации Go

**[Открыть сборник в HTML](index.html)** · **[Все задачи в Markdown](TASKS.md)** · [К учебнику](../index.html)

Формат каждой задачи: полная программа → «скомпилируется ли, что выведет, будет ли panic?» → раскрываемый ответ и объяснение правила. В HTML доступны выбор темы, поиск по номеру/названию/коду и случайная задача в пределах фильтра. Работает автономно при открытии файла, без сервера и интернета. Печать выдаёт лист заданий без ответов.

Первые 400 задач (001–400) сохранены без изменений. Всего 40 тем по 20 задач. Первые 20 тем: константы; числа; определённые типы и алиасы; идентичность и присваивание; интерфейсы; сравнимость; методы; встраивание; срезы; массивы; карты; функции; каналы; инстанциации; ограничения; вывод типов; reflect.Type; reflect.Value; Unicode; составные задачи с памятью и итераторами.

Практические API и составные примеры помогают переносить правила типизации на адаптеры, сериализацию и ленивые цепочки. Отдельный фильтр и ссылка с главной позволяют сразу открыть добавленный набор.

## Как решать

1. Определите статические типы всех участвующих выражений.
2. Для интерфейсов отдельно назовите динамический тип и значение.
3. Разделите допустимость программы и поведение при исполнении.
4. Предскажите stdout и объясните, какие значения копируются, а какая память остаётся общей.
5. Для ошибки предложите минимальное исправление и поясните, как оно меняет договор.

Есть сложные сочетания правил и контрольные контрпримеры. Короткий код не всегда означает простой вопрос. Сценарии с recover нужно читать буквально: перехваченная panic может давать обычный вывод `true`, не завершая процесс аварийно.

## Версия и проверка

Базовая версия — **Go 1.23.0**. Проверено на darwin/arm64. Новые правила Go 1.24–1.27 не следует переносить на эти ответы: в частности, generic-методы и ключи литералов рассматриваются по правилам 1.23. Сборник не претендует на проверку ещё не включённых возможностей последующих версий.

```sh
node interview/verify.mjs
node interview/build.mjs
node --test interview/artifacts.test.mjs
```

Проверка запускает четыре компиляции параллельно, затем выполняет успешно собранные программы с ограничением времени. По умолчанию выбирается `GOTOOLCHAIN=go1.23.0`; если toolchain ещё не установлен, Go может загрузить его. Кэш сборки по умолчанию находится в `/tmp/gotypes-review-cache`. Через `GOCACHE` можно указать другой каталог. Заданный явно `GOTOOLCHAIN` позволяет проверить отличия другой версии, но результаты такого запуска нужно интерпретировать с учётом правил этой версии.

У каждой задачи заранее заданы ожидаемые stdout или фрагмент диагностики компилятора и объяснение. Исполнение не генерирует ответы автоматически. Завершающие пробельные символы stdout не учитываются. Panic в некоторых задачах намеренно перехвачена. Полный текст сообщения компилятора, номера строк и временные пути не входят в договор.

Можно проверить несколько задач: `node interview/verify.mjs 274 366 400`. Частичная проверка не заменяет свидетельство проверки всего сборника.

## Откуда берутся файлы

- `catalog.mjs` — исходные 400 задач; `catalog-extra.mjs` — задачи 401–600; `catalog-exam.mjs` — экзаменационные 601–800; `all-tasks.mjs` объединяет каталоги, сохраняя номера.
- `verify.mjs` — компиляция и проверка результатов каждой независимой программы.
- `verification.json` — версия компилятора, число успешных проверок и хеш проверенного каталога.
- `build.mjs` — форматирование программ, Markdown и автономный HTML; сборка требует полной проверки текущего каталога.
- `testdata/001.go` … `testdata/800.go` — независимые полные программы. Каталог testdata исключён из обычного `go test ./...`, поскольку часть программ намеренно неверна.
- `app.js`, `style.css` — навигация и оформление сборника.

Пример запуска одной корректной программы:

```sh
GOTOOLCHAIN=go1.23.0 go run interview/testdata/001.go
```

Не запускайте `go run interview/testdata/*.go`: это 800 независимых программ с отдельными объявлениями `main`.

Текущая онлайн-спецификация описывает более новый Go; для версионных вопросов учитывайте release notes и зафиксированную версию сборника.
