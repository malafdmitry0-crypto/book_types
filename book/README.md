# Обобщённое программирование в Go: от первых решений к параметрам типов

Учебник строится вокруг вопроса: как написать один алгоритм для разных данных, сохранив понятные правила типов, ошибок и результата? Сначала работаем с Fraction, Money и BoxInt в модели раннего Go. Затем сравниваем альтернативы и возможности новых версий.

[HTML](../index.html) · [Весь код и команды запуска](../lessons/README.md) · [Типы и методы](../TYPES.md)

## Как проходить учебник

1. Прочитайте постановку задачи в начале главы.
2. Откройте ссылку «Код главы», найдите Example и предскажите его вывод.
3. Запустите пример, затем вернитесь к объяснению механизма.
4. Ответьте на вопрос в конце: что изменилось в API и какую гарантию это добавило?

Не нужно читать весь справочник до начала курса. Обращайтесь к нему, когда встретится конкретный вопрос о конверсии, assertion, методах или памяти.

## Где искать примеры

[lessons/README.md](../lessons/README.md) — единый каталог. Там разделены запускаемые сценарии, ожидаемые ошибки компиляции и точные выдержки каждого Go-блока. Реализации ранней библиотеки остаются в algorithms; отдельные сравнительные реализации — в examples.

Проект проверяется современным Go. Файлы для Go 1.26 и 1.27 находятся в коде с условиями сборки и на Go 1.25.4 исключены. Исторический стиль алгоритма не означает совместимость всего репозитория с Go 1.0.
