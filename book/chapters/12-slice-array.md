# 12. Срез → значение массива: Go 1.20

Код главы: [example_test.go](../../lessons/reference/basics/example_test.go) · [failures_test.go](../../lessons/failures/failures_test.go).


> Цель главы: Отличать копию массива от указателя на общие элементы.

Теперь получим значение массива вместо указателя. Сравните этот эксперимент с разделом о Go 1.17: изменение массива уже не меняет исходный срез.

```go
s := []int{10, 20, 30}
a := [2]int(s)
a[0] = 99 // s[0] остаётся 10

// _ = [4]int(s) // panic: len(s) < 4
```

В отличие от `*[N]T`, `[N]T` копирует элементы. Копирование неглубокое: если элемент содержит указатель или срез, его данные могут остаться общими. `nil`-срез допустимо преобразовать в `[0]T`. Источник: [Go 1.20](https://go.dev/doc/go1.20#language).
