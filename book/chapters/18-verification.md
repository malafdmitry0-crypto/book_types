# 18. Версии, источники и проверка

Код главы: [каталог и команды](../../lessons/README.md) · [условия новых версий](../../lessons/reference/modern/method_go127_test.go).

Срез исторического материала — 5 сентября 2026 года. Источники — официальные спецификация, release notes и документация стандартной библиотеки, указанные рядом с правилами. Для Go 1.26 и 1.27 сведения повторно сверены с [Go 1.26](https://go.dev/doc/go1.26#language) и [Go 1.27](https://go.dev/doc/go1.27#language).

## Что именно проверено

Полные сценарии основного курса и справочника проверяются Go 1.25.4. Example сравнивает stdout с Output. Отдельные тесты проверяют частичные результаты, остановку обхода, паники и отказы компилятора. Markdown-фрагменты могут опускать окружение: их точные копии лежат в snippets/testdata, а полные сценарии указаны в каждой главе.

## Что зависит от версии

Корневой модуль требует Go 1.23. Для generic aliases нужен Go 1.24; для самоссылок в новых ограничениях — Go 1.26; для собственных параметров типов методов — Go 1.27. Последние два набора исходников исключены на Go 1.25.4 условиями сборки. Их наличие не является заявлением о локальном прохождении тестов новым компилятором.

## Как воспроизвести проверку

```sh
go test ./...
go vet ./...
go -C examples test ./...
go -C examples vet ./...
node scripts/sync-snippets.mjs --check
node scripts/build.mjs
```

Модуль examples проверяется отдельно. Исторический API алгоритма и минимальная версия всего проекта — разные характеристики: методы значений используют современные библиотеки.
