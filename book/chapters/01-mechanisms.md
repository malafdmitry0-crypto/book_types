# 1. Что именно называют приведением

Код главы: [example_test.go](../../lessons/reference/basics/example_test.go) · [example_test.go](../../lessons/reference/typeinterfaces/example_test.go).


> Цель главы: Различать конверсию, проверку типа и преобразование данных.

Начните с вопроса: нужно получить другое значение, проверить уже хранимый тип или разобрать текст? Таблица ниже разводит эти задачи; следующие разделы позволяют проверить каждую на коде.

| Механизм | Пример | Что происходит |
|---|---|---|
| Явная конверсия | `int64(n)` | Получаем значение целевого типа по правилам языка |
| Контекст для константы | `var n int64 = 42` | Нетипизированная константа получает тип |
| Присваивание | `var s []int = namedSlice` | Используем совместимость типов без явной конверсии |
| Присваивание интерфейсу | `var x any = n` | Сохраняем конкретное значение с его динамическим типом |
| Type assertion | `n, ok := x.(int)` | Проверяем динамический тип интерфейсного значения |
| Type switch | `switch v := x.(type)` | Выбираем ветку по динамическому типу |
| Алиас | `type ID = int64` | Даём существующему типу другое имя |
| Дженерики | `Convert[int64](n)` | Обобщаем алгоритм; внутри всё ещё нужны допустимые операции |
| Reflection | `v.Convert(t)` | Выполняем допустимую конверсию с типом, известным во время исполнения |
| Parsing / formatting | `strconv.Atoi(s)` | Разбираем или создаём текстовое представление |
| Маппинг / адаптер | `ToDTO(user)` | Явно задаём смысл преобразования данных или поведения |
| `unsafe` | `(*T)(unsafe.Pointer(p))` | Работаем с представлением памяти при специальных ограничениях |

`T(x)` и `x.(T)` решают разные задачи. Даже если `x` содержит `int`, выражение `x.(int64)` не преобразует это число.
