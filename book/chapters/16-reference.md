# 16. Таблица выбора

> Цель главы: Самостоятельно выбирать подходящий механизм.

| Задача | Подход | Что проверить |
|---|---|---|
| `int32 → int64` | `int64(x)` | Допустимость исходного типа |
| `int64 → int8` | Проверка диапазона, затем `int8(x)` | Потеря старших битов |
| `float64 → int` | Проверка диапазона, затем `int(x)` | Дробь, NaN, Inf |
| Число ↔ текст | `strconv` | Формат, основание, диапазон, ошибка |
| Строка ↔ байты / руны | `[]byte`, `[]rune`, `string` | UTF-8 и нужное представление |
| `any → конкретный тип` | `v, ok := x.(T)` | Точное совпадение динамического типа |
| Несколько runtime-типов | Type switch | Обработка неизвестного типа и nil |
| Поведение через интерфейс | Присваивание / assertion | Method set, pointer receiver, typed nil |
| Совместимые определённые типы | `Target(x)` | Семантика и общая память |
| Несовместимые структуры | Явный маппинг | Поля, единицы измерения, валидация |
| Новый тип элементов среза | Цикл / generic `Map` | Копирование, nil, возможные ошибки |
| Первые N элементов как массив | `[N]T(s)` | Длина, копирование |
| Общие элементы как указатель на массив | `(*[N]T)(s)` | Длина, совместное изменение |
| Тип известен только в runtime | `reflect` | `IsValid`, `CanConvert`, доступность записи |
| Общее имя того же типа | Алиас | Нужна ли отдельная идентичность |
| Общий типобезопасный алгоритм | Дженерики | Достаточность ограничения |
| Другой взгляд на биты | Специализированный API / `unsafe` | Представление памяти, GC, время жизни |
