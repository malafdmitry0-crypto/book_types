# Обобщённое программирование в Go

**Как всё начиналось: общие алгоритмы на интерфейсах, индексах и адаптерах.**

Учебник объясняет, как развивались способы обобщения алгоритмов: конкретные типы и callback, индексы и замыкания, поведенческие интерфейсы, `interface{}`, reflection, генерация кода, параметры типов и итераторы.

## Три части одного учебника

Главы 1–10 посвящены раннему Go: от конкретных функций к замыканиям и интерфейсам коллекций по образцу `sort.Interface`. Разбираем настоящие `Fraction`, `Money`, `BoxInt` и пакет `algorithms`: поиск, проверки, преобразование, накопление и сортировку. Показываем полный адаптер, путь вызова, место хранения результата и поведение при ошибках.

Главы 11–18 объясняют альтернативы и дальнейшее развитие: `interface{}`, reflection, генерацию, параметры типов, стандартные алгоритмы и итераторы. Эти подходы не были последовательными заменами друг друга. Существующие восемь реализаций на `User` остаются дополнительным материалом в `examples/`.

Справочник — все прежние 18 глав о конверсиях и системе типов, переработанные для последовательного чтения в том же учебнике.

Find, All и Map — названия учебных алгоритмов. В частности, `slices.All` возвращает итератор и не является проверкой предиката «все подходят».

## Читать и редактировать

Откройте `index.html` в браузере двойным щелчком. Интернет и сервер не нужны. Есть поиск по полному тексту, три группы оглавления, переходы между главами, копирование примеров и печать всего учебника в PDF.

Введение позволяет переключать Find, Map, Sum и Sort и видеть, что знает алгоритм и что остаётся адаптеру. Это иллюстрация API, а не запуск Go в браузере.

Изменяйте Markdown в `book/chapters/`. После правок пересоберите HTML:

```sh
node scripts/sync-snippets.mjs
node scripts/build.mjs
```

Сборка использует только встроенные модули Node.js. Поддержан используемый набор Markdown: заголовки, абзацы, нумерованные списки, цитаты, таблицы, ссылки, жирный текст и код. Это специализированный сборщик, не универсальная реализация CommonMark. `index.html` не нужно редактировать вручную.

## Проверить алгоритмы

Модули проекта требуют Go 1.23 или новее. Ранний Go здесь означает способ проектирования API; совместимость всего проекта с компилятором Go 1 не заявляется. Из корня:

```sh
go test ./...
go vet ./...
go -C examples test ./...
go -C examples vet ./...
go -C examples generate ./...
```

Полные реализации и тесты проверены на Go 1.25.4. Полные сценарии содержат импорты, вызовы и ожидаемый результат; точные выдержки всех Go-блоков хранятся отдельно с указанием их контекста. Справочные примеры вынесены в lessons/reference; ожидаемые ошибки — в lessons/failures. Сценарии Go 1.26–1.27 исключены условиями сборки на Go 1.25.4. Методика сравнения производительности дана в основном курсе, неподтверждённые benchmark-цифры не приводятся.
