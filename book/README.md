## Как работать с материалом

Читайте основной курс последовательно: в каждой главе меняется одно требование к библиотеке. Сравнивайте типы входа и результата, место проверки ошибок и код, необходимый при добавлении Order вместо User. После этого используйте справочник для конкретных правил конверсий, assertions, method sets и ограничений.
