# Законы операций

[Example](example_test.go) показывает отличие == от Equal, невалидное нулевое значение, нейтральный 0/1 и переполнение при смене группировки.

[laws_test.go](laws_test.go) проверяет законы равенства и порядка, коммутативность, ограниченную ассоциативность и нейтральный элемент. Небольшие числители и знаменатели в fuzz-тесте гарантируют представимость промежуточных результатов; границы int64 проверяются отдельным контрпримером.

```sh
go test ./lessons/laws -v
go test ./lessons/laws -run '^$' -fuzz '^FuzzFractionLaws$' -fuzztime=5s -parallel=2
```

Успешный fuzz-запуск не является доказательством закона на всех возможных входах.
